# Planilhas Fáceis

Vitrine em Next.js com planilhas em destaque e páginas para os segmentos de construção e odontologia.

## Rodar localmente

Com Git e nvm instalados, use a versão de Node do arquivo `.nvmrc`.

```bash
git clone https://github.com/bagaaz/planilhas.git
cd planilhas
nvm install
nvm use
npm ci
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
